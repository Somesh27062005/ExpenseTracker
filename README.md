# 💸 Expense Tracker App — MERN Stack

A full-stack web application to track your expenses and income. Built with the MERN stack (MongoDB, Express, React, Node).

🌐 **Live Demo**: [https://somesh-expense-tracker.vercel.app/](https://somesh-expense-tracker.vercel.app/)

---

## ✅ Features

- 👤 User authentication (Signup / Login)
- 💰 Add new transactions (Expense or Income)
- 📝 View list of all transactions
- 📊 Display total balance, total expenses, and total income
- ✏️ Edit / Update existing transactions
- ❌ Delete transactions
- 🌐 Responsive frontend built with React & Tailwind CSS
- 🔄 Backend using Express + MongoDB to store and manage data

---

## 🛠️ Tech Stack & Project Structure

- **Frontend**: React, Vite, Tailwind CSS (Hosted on [Vercel](https://vercel.com))
- **Backend**: Node.js, Express.js (Hosted on [Render](https://render.com))
- **Database**: MongoDB Atlas
